# MATA37_ILP_TURMA08

# 📚 Introdução à Lógica de Programação

> "Antes de existir software, existe lógica. Antes de existir lógica, existe a capacidade de resolver problemas."

Este repositório reúne as atividades práticas desenvolvidas pelos estudantes da disciplina **Introdução à Lógica de Programação**, com foco no desenvolvimento do raciocínio algorítmico, análise de problemas e construção de soluções computacionais.

---

## 🎯 Objetivo

O propósito deste projeto é exercitar os fundamentos da lógica de programação por meio da implementação de algoritmos construídos passo a passo, priorizando:

* Estruturas condicionais;
* Estruturas de repetição;
* Vetores e matrizes;
* Manipulação de strings;
* Funções;
* Desenvolvimento do raciocínio lógico.

---

## 👥 Organização das Equipes

O repositório está dividido em grupos temáticos:

```text
📂 Squad 01 - Grafos
📂 Squad 02 - Estruturas de Árvore
📂 Squad 03 - Redes e Caminhos
📂 Squad 04 - Caixeiro Viajante
📂 Squad 05 - Busca Semântica e Recuperação de Informação
```

Cada integrante possui uma pasta individual dentro do respectivo grupo para armazenar suas implementações, experimentos e versões das atividades.

Exemplo:

```text
Squad 01 - Grafos/
│
├── João/
│   ├── atividade1.cs
│   └── atividade2.cs
│
├── Maria/
│   ├── atividade1.cs
│   └── atividade2.cs
│
└── Pedro/
    ├── atividade1.cs
    └── atividade2.cs
```

## 🧠 Filosofia do Projeto

A programação não começa digitando código.

Ela começa quando transformamos um problema em uma sequência lógica de passos.

Este repositório representa justamente esse processo: diferentes estudantes, diferentes estratégias e diferentes formas de raciocinar sobre o mesmo desafio computacional.
